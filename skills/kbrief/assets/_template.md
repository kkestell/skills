# Brief title

Write the brief after the user has settled the decisions. Delete unused headings and placeholder text, including this guidance.

## Problem

What is wrong or missing, for whom, and why it matters.

## Outcome

What the user can do or will see when the change is done, described from outside the system. This is what the finished work is checked against.

## Decisions

The choices the user made or approved, most important first.

- **The choice.** Why the user wants it. Turned down: the other options considered, and why.

## Out of scope

- What this change deliberately leaves out.

## Left to the plan

- A question the user chose to leave to the planner, with any preference they gave.
